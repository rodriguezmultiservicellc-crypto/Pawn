# Sol Pawn — code and UI review, 2026-11-11

Read-only review of the whole app at commit `eb907e0`. Nothing was changed.
Four reviewers each read one slice of the code (security and tenancy, money
and data integrity, UI code, performance and architecture). The screens were
reviewed from the browser-smoke screenshots of 2026-11-04 plus the New repair
ticket and laser screens driven on 2026-11-10.

**How to read the status column**

- **Verified** — re-read in the code by the lead reviewer, or confirmed against
  live state.
- **Reported** — found by a slice reviewer with file and line evidence, not
  independently re-read.
- **Unverified** — depends on something outside the repo (platform setting,
  device behaviour).

Paths are relative to the repo root. `src/app/(staff)` is shortened to `(staff)`.

## 7. Suggested order

1. **Close the seven items in section 1.** Items 1, 2, 5 (debug action), 6 and
   7 are small, contained changes. Item 3 needs your confirmation because it
   touches RLS. Item 4 is a rewrite of the refund calculation.
2. **Make money movements atomic** (section 2): one database function each for
   pawn intake, loan payment, redeem, forfeit, sale completion, return and
   layaway payment, shared by the staff actions and the webhook. This also
   closes the double-submit races.
3. **One shop-timezone date helper** used for accrual, due dates, report
   ranges and display. Closes finding 10, the report day boundaries, the three
   date formats and the production hydration warnings together.
4. **Move report totals into SQL** before the first tenant passes 1,000 sales
   in a range.
5. **Counter usability pass**: default tax rate, payoff panel aware of loan
   status, translated errors, staff `error.tsx` / `loading.tsx`, sidebar
   collapse below 1024px, name search on pawn and repair lists.
6. **Shared UI primitives** (`Button`, `Input`, `Field`, `Modal`) and a 12px
   text floor with a darker muted colour. Do this before building more
   screens; every new screen currently adds to the drift.
7. **Refresh CLAUDE.md** from the repo.
